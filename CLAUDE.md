## Agent skills

### Issue tracker

Issues live as GitHub issues on `jessietw2019-cyber/citysoul` (private repo), managed via the `gh` CLI, and are also mirrored to local-only files under `docs/issues/` (GitHub is authoritative). See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the five default canonical labels as-is: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: `CONTEXT.md` at repo root + `docs/adr/`, plus a consolidated `docs/SDD.md` and a spec-document reading-order index at `docs/city_soul_AR_document_index.md`. See `docs/agents/domain.md`.
